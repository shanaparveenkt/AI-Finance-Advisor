# 💰 AI-Powered Personal Finance Advisor

AI-powered personal finance advisor with behavioral analytics, expense prediction, and smart budgeting dashboard built using Streamlit.

This project is an intelligent personal finance system that analyzes user spending behavior, identifies patterns, predicts future expenses, and provides actionable financial recommendations using Machine Learning and Data Analytics. It is designed as an interactive dashboard to help users understand and improve their financial habits in a simple and visual way.

## 🚀 Features

- Spending Analysis: Category-wise expense tracking including Food, Travel, Bills, Essentials, Shopping, and Others along with monthly spending trends.
- Behavioral Analytics: Analysis of weekend vs weekday spending patterns to understand user behavior.
- Machine Learning Prediction: Future spending prediction using Linear Regression.
- Anomaly Detection: Identification of unusual or high-value transactions.
- AI Recommendation Engine: Personalized financial suggestions based on user behavior.
- Financial Health Score: Overall financial stability score out of 100.
- Interactive Dashboard: Built using Streamlit for real-time insights and visualization.

## 🛠️ Tech Stack

Python, Pandas, NumPy, Scikit-learn, Streamlit, Matplotlib

## 📂 Project Structure

AI-Finance-Advisor/ ├── app.py ├── Personal_Finance.csv ├── requirements.txt └── README.md

## 📊 Dataset Information

The dataset contains simulated real-world financial transactions including daily income and expenses over 90+ days, categorized into Food, Travel, Bills, Essentials, Shopping, and Others with different payment modes such as UPI, Cash, Card, and Bank transfers.

## ▶️ How to Run Locally

Clone the repository using git clone https://github.com/yourusername/AI-Finance-Advisor.git then navigate into the folder using cd AI-Finance-Advisor then install dependencies using pip install -r requirements.txt and finally run the Streamlit app using streamlit run app.py

## 🌍 Deployment

This project can be deployed using Streamlit Cloud by uploading the repository to GitHub, connecting it with Streamlit Cloud, and deploying the app instantly. Live Link: https://your-streamlit-app-link.streamlit.app
